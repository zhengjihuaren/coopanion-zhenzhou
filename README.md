## 安装

1. 下载 Releases 里的 `shirana-v0.1.0.zip`（不用解压）。
2. 打开 Coopanion → 「装扮」→「形象」→「导入」，选中这个 zip。
3. 导入完成后，在形象列表里选「椎名真昼」。

也可以导入解压出来的 `shirana` 文件夹。

## 内容

- 19 种表情：平静、开心、眨眼、喜欢、害羞、惊讶、生气、难过、犯困、思考、
  得意、嘟嘴、担心、认真、慌张、害怕、期待、大哭、疑惑。
- 18 种动作：站起、跳、小跳、张望、转身、点头、摇头、转圈、坐下、睡觉、
  晕、走走、跑、招手、鞠躬、发抖、扑腾、跳舞。
- 支持光标视线、自然眨眼、说话口型、倾听、思考、拎起与抛落。
- 头发、呆毛、刘海、手臂、裙摆、双腿、眉毛分别绑定；坐姿使用 PSD 里独立的坐姿分片。

`manifest: 2`、`api: 2`，形象包 ID `shirana`，版本 `0.1.0`。
按 Coopanion v0.1.24 制作（上游提交 `91293b3e31b94397a8f2eb79dffec40f4c6d8817`）。

## 制作

原画与分层 PSD 由使用者提供。透明分片从 PSD 按图层导出，放在 `tex/`；
表情件（眼白、虹膜、睫毛、嘴）放在 `feat/`，其余表情在运行时绘制。
其中「眯眼弧线」与若干表情嘴片取自同系列的 Claude 娘形象包（同作者制作）。
声音与身体运动使用应用提供的 kit，包内不附带音频。此包只有原画配色。
